Espace cabinet — première connexion sur cet appareil

À faire une seule fois par ordinateur ou téléphone. Ce certificat permet une connexion chiffrée avec le serveur du cabinet ; il ne sert qu'au réseau du cabinet.

1. Télécharger le certificat du cabinet

Ordinateur Windows

  1. Ouvrir le fichier cabinet-nouha-ca.crt téléchargé, puis Installer le certificat…
  2. Choisir Ordinateur local (ou Utilisateur actuel), puis Placer tous les certificats dans le magasin suivant.
  3. Parcourir… → Autorités de certification racines de confiance → OK → Suivant → Terminer → Oui.
  4. Fermer complètement le navigateur et le rouvrir.

Téléphone Android

  1. Télécharger le certificat ci-dessus.
  2. Paramètres → Sécurité (ou Sécurité et confidentialité) → Plus de paramètres → Chiffrement et identifiants → Installer un certificat → Certificat CA.
  3. Confirmer « Installer quand même », puis choisir le fichier cabinet-nouha-ca.crt.

iPhone

  1. Ouvrir cette page dans Safari et télécharger le certificat → « Autoriser ».
  2. Réglages → Profil téléchargé → Installer.
  3. Réglages → Général → Informations → Réglages des certificats → activer « Cabinet Dr Nouha Ksiksi ».
2. Ouvrir l'espace cabinet → https://cabinet-nouha.local
