Espace cabinet — première connexion sur cet appareil

À faire une seule fois par PC du cabinet. Le plus simple : lancer POSTE-CABINET.cmd (paquet Staff) sur ce PC, qui fait tout seul les étapes ci-dessous et crée le raccourci du bureau. Sinon, à la main :

1. Télécharger le certificat du cabinet

PC Windows (Edge ou Chrome)

  1. Ouvrir le fichier cabinet-nouha-ca.crt téléchargé, puis Installer le certificat…
  2. Choisir Ordinateur local (Windows demande l'accord d'un administrateur), puis Suivant.
  3. Cocher Placer tous les certificats dans le magasin suivant → Parcourir… → Autorités de certification racines de confiance → OK → Suivant → Terminer.
  4. Message « L'importation a réussi ». Fermer complètement le navigateur et le rouvrir.
2. Ouvrir l'espace cabinet → https://cabinet-nouha.local
